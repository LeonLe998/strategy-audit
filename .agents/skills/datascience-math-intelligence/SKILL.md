# Data Science & Quantitative Mathematics Intelligence Skill

## Overview
This skill provides access to and guidance on utilizing statistical, econometric, and mathematical methodologies to validate quantitative trading strategies, estimate tail risk, and eliminate data snooping biases.

## Key Capabilities
1. **Monte Carlo Permutation Testing & P-Hacking Guard**:
   - Run 10,000 randomized permutations of trade returns to compute the exact p-value against the null hypothesis.
   - Calculate theoretical and empirical Risk of Ruin probabilities.

2. **Bayesian Statistical Inference**:
   - Update win-rate probability density using conjugate priors (Beta-Binomial) on live or backtested out-of-sample trades.

3. **Time Series Econometrics**:
   - Stationarity verification using Augmented Dickey-Fuller (ADF) test (p < 0.05).
   - Volatility clustering and heteroskedasticity modeling using GARCH(1,1).

4. **Machine Learning & Walk-Forward Validation**:
   - Purged & Embargoed K-Fold cross-validation preventing information leakage from overlapping labels.

5. **3D Mathematical Modeling**:
   - Render bivariate Gaussian surfaces, Lorenz chaotic attractors, and option volatility smile topologies in real-time WebGL.
